# You're the Manager

中英双语互动网页，围绕一位初级开发者的经历，讨论 AI 使用、学习机会、团队风险与长期成长。

页面采用分屏步骤：封面 → 三次情境决策 → 核心结论，每次只展示当前需要阅读和判断的内容。选择方案后，页面会直接在对应答案下方展开“短期结果、长期影响、底层逻辑”。中英文使用相同字号并排展示，也可以切换为纯中文或纯英文。

## 打开方式

最简单的方式是双击 `打开网页.command`，它会自动启动本地服务并在浏览器中打开页面。这个终端窗口需要保持开启，关闭后网页服务会停止。

也可以直接双击 `index.html` 浏览。若浏览器限制本地文件功能，请在项目目录运行：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 页面功能

- 双语、仅中文、仅英文三种阅读模式
- 三次情境决策与即时课程反馈
- 本地保存选择，刷新后仍会保留
- 终局投票、决策摘要复制、重新开始
- 响应式布局、键盘操作、减少动态效果适配

页面不依赖框架、字体服务或外部图片，可以直接部署到任意静态网站托管服务。
